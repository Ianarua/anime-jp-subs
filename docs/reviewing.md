# 人工评审 + 打分：改断句算法的标准流程

> ⚠ 这两个工具**只在 `dev` 分支**（`qa/`），用户版（`main`）里没有。

断句对不对，机器测不出来，**只能靠耳朵**。所以流程是：

```
处理一集(留下听写结果)  →  生成评审页  →  边看边标  →  导出标记  →  打分  →  改算法  →  再打分
```

这套流程把"感觉不对"变成了一个可量化的数字：断句算法就是靠一集 **80 条标记**，从"一处都不对（0/80）"改到"对 44 处（55%）"的。

---

## 1. 先处理一集，并留下听写结果

```bat
run_jp_sub.bat process --keep-dump "D:\Anime\2026.7\某番"
```

`--keep-dump` 会在 mkv 旁边写一份 `<集名>.jp.dump.json`（Whisper 的段/词 + VAD 语音段/停顿）。打分靠它复算，不用再跑一遍 Whisper（一集省 1 分钟）。

## 2. 生成评审页

```bat
run_jp_sub.bat review "D:\Anime\2026.7\某番"        :: 已有就跳过；想重做加 --force
```

每集旁边生成两个文件（**不改动 mkv，删掉即还原**）：

| 文件 | 用途 |
|---|---|
| `<集名>.review.html` | 双击用浏览器打开：每条字幕一行，标「并入上一条 / 并入下一条 / 拆分 / 这里漏字幕 / 备注」，标完点导出 |
| `<集名>.review.txt` | 同样的清单，纯文本版 |

页面会自动标出切分类的可疑点（识别错字不在内）：

| 标记 | 意思 |
|---|---|
| ⚠跨停顿 | 这一条的显示区间盖住了一整段长静音——很可能是"两句被并成一句" |
| ⚠行首助詞 | 这一行从助詞开头（断点很可能该往前挪） |
| ⚠行尾起句 | 行尾是「いや / あの / え」这种只会起句的词（应该归下一行） |
| ⚠偏长 | 一条显示超过 8 秒或 24 字 |

## 3. 打分

```bat
run_jp_sub.bat score 标记.txt --baseline E11.jp.ass --dump E11.jp.dump.json -v
```

三样输入缺一不可：

| 参数 | 是什么 | 为什么 |
|---|---|---|
| `标记.txt` | 评审页导出的那段纯文本 | 验收标准 |
| `--baseline` | **人当时审的那份产物**（.ass / .srt） | **标记的行号属于它**——代码一改行号就漂，拿新产物去对旧行号会全错（踩过，整轮评分作废） |
| `--dump` | 那集的 `.jp.dump.json` | 打分要用当前代码复算切分结果 |

口径（**钉死，别改**）：

- **合并**标记 = 那个词缝上**不该**有切点；**拆分**标记 = **该**有切点；
- 允许**差一个词缝**（±1）——人点的是"这两句该分开"，落在相邻词缝上阅读体验一样。

输出示例：

```
打分（口径：允许差一个词缝）
  行数 310  切点 309
  不该断（合并）：14/23
  该断（拆分）：  30/57
  合计：44/80 = 55.0%
```

`-v` 会把**没通过的逐条列出来**（带时间码），方便回听确认是"算法错了"还是"当时标错了"。

---

## 4. 改完算法后必须做的三连回归

| 检查 | 及格线 |
|---|---|
| `python -m unittest discover -s tests -t .` | 全过（现在 159 个，2 个跳过） |
| `score …` 复算同一集 | **不低于 44/80**（涨了要能解释为什么） |
| 端到端跑一集**副本** | 行数、ffprobe 自检（jpn 标签 / 轨道顺序 / 只剩两条字幕）、字体附件都对 |

任何一项不过就回退——**别在没说清原因的情况下把分数改低**。

---

## 5. 踩过的坑

1. **基准必须钉死**：标记的行号属于"人审的那份产物"，所以 `--baseline` 是必填参数，不是可选的默认值。
2. **别改打分口径**：把 ±1 改成 0、或者把"合并/拆分"的方向搞反，历史数据全部作废。
3. **人工标记只标"切分"**：识别错字（听到的词不对）不算——那属于 ASR 质量问题，跟断句算法是两件事。
4. **标完立刻导出**：页面把标记存在浏览器 localStorage 里，但 `file://` 下有些浏览器不让存，页面会弹提示；看到提示就别关标签页（或者随时点一次导出留底）。
5. **OP/ED 不做特殊处理**：歌词也算正文，口径是一视同仁（评到主题曲那段不用纠结，该标就标、该漏就漏）。
